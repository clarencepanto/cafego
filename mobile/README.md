# CafeGo Mobile

React Native app built with Expo.

## Setup

```bash
# 1 — install dependencies
cd mobile
npm install

# 2 — set your local IP in constants/config.js
# Replace YOUR_LOCAL_IP with your Mac's WiFi IP
# Find it: System Settings > WiFi > Details > IP Address

# 3 — start Expo
npx expo start

# 4 — scan the QR code with Expo Go on your phone
```

## Requirements
- Node.js 18+
- Expo Go app on your iPhone (free from App Store)
- Your Mac and iPhone on the same WiFi network
- Server running: cd ../server && node index.js
